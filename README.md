# Desktop EPUB Reader (Electron + foliate-js)

一个基于 Electron 和 `foliate-js` 开发的轻量、无边框沉浸式桌面 EPUB 电子书阅读器（专为摸鱼设计）。

## ✨ 核心功能
- **沉浸式摸鱼模式**：支持 `F1` 快捷键一键隐藏顶部栏与边框，实现真正的无感知阅读。
- **注释弹窗**：EPUB中注释内容，点击弹窗展示，菜单中可以开关隐藏文末注释内容
